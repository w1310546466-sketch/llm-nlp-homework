# 一条提示经验怎么才算是被验证过

**出处**：第三讲 part1 第 66 页。

**题目**：研究练习——让一条提示经验接受检验。

**题面**：选择一个真实失败，提出能区分解释的实验，并说明什么结果会改变判断。课件给了三个候选假设：

- 详细步骤帮助模型处理条件关系
- 专家角色提升事实准确性
- 自动批评改善译文

**课件要求**：先写清评价协议再跑实验，避免结果出来以后修改成功标准；保留原始输出、配置、样本划分、完整费用和失败案例；没有运行的数据保持空白。

## 我选哪一条

选第二条，专家角色。原因很实际：这条最容易验证，也最容易证伪。前两条涉及"步骤"和"批评"的质量，评价标准本身就有争议；"专家角色"只影响事实类判断，对错可以人工核对。

我的初始判断是：**角色设定基本没用，起作用的是角色后面那些具体要求**。如果这个判断成立，那"你是资深法务专家"这句话单独拿出来应该和没有一样，而"核对法条编号与生效日期"单独拿出来就该有效果。

## 设计

四种条件，2×2：

| | 无工作标准 | 有工作标准 |
|---|---|---|
| 无角色 | A 基线 | B |
| 有角色 | C | D |

- A：直接问
- B：加一句"核对法条编号与生效日期，标注不确定处"
- C：加"你是执业二十年的法务专家"
- D：两个都加

**判断逻辑**：如果 D 明显好于 A，而 C 与 A 无差异、B 与 D 无差异，说明收益来自工作标准，角色只是装饰。反过来，如果 C 就有效果，我的判断错了。

篇幅必须固定。角色那句话会增加 token，长度本身就是变量，所以 A 和 C 要补一段等长的无关说明（比如"请用中文回答"重复到相仿长度），否则分不清是角色起作用还是长度起作用。

## 样本

三十道题，全部来自真实法律咨询场景的公开问答，答案可以人工核对。按题型分三层：条文检索（答案唯一）、条件判断（需要综合两条以上）、不确定情形（材料不足，正确行为是说明缺失）。每层十道。

开发集和测试集按题型模板划分，不能让同一模板的轻微改写同时出现在两边。

## 评价

主指标是事实正确率，人工逐条核对，不看模型自评。

次指标是"过度自信率"：在材料不足的题上给出确定答案的比例。这一项是角色提示最容易出问题的地方——专家角色会诱导模型装懂。

第三项是长度。如果 C 组回答普遍更长，而正确率没变，那说明角色只改变了语气。

## 什么结果会推翻我

有三种：

1. C 组显著优于 A，而 B 与 D 差不多。那说明角色本身有效，我的判断错。
2. D 组优于 B，但 C 组也优于 A，且差距接近。那说明两者独立起作用，不是"标准才是真的"。
3. 所有组在测试集上都没有差异，但在开发集上有。那说明之前的差异来自题目选择，不是提示。

第三种最值得警惕，也最容易被忽略。很多"提示工程经验"就是这么来的：在一小批题上调出来，换一批就没了。

本文是实验计划，没有运行结果。
