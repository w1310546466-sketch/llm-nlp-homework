# 第三讲：思考题六篇

第三讲的作业都是思考题，不要求跑实验。课件对这类题的说法是"先写清评价协议再跑实验"，并允许在没有调用条件时把结果写成实验计划、不填模拟数据。下面六篇按这个原则处理，每篇开头写明出处和题面。

| 文件 | 题目 | 出处 | 性质 |
|---|---|---|---|
| [C3](C3_后训练技术演进.md) | 大语言模型后训练技术的演进 | part2 第 226 页 | 思考题（课件标注"考虑必做"），综述为主 |
| [C1](C1_提示词泄漏调研.md) | 泄露的提示词与越狱方法 | part1 第 15 页 | 思考题，只做公开材料分析 |
| [C2](C2_提示经验检验.md) | 让一条提示经验接受检验 | part1 第 66 页 | 研究练习，只给设计 |
| [C4](C4_宪法规则与提示词.md) | 宪法规则是不是泄露的提示词 | part2 第 126 页 | 思考题，论述 |
| [C5](C5_唐诗宋词英译.md) | 唐诗宋词的英译方法 | part1 第 89 页 | 实验思考题，手写三版对照 |
| [C6](C6_DPO与其他RL对比.md) | DPO 与其他强化学习训练对比 | part2 第 124 页 | 思考题，论述 |

## 哪些跑了，哪些没跑

C3 里的代码追踪是真做的：浅克隆了 TRL，逐行对过 DPO 和 GRPO 的实现，行号写在正文里。

C3 的综述、C4 的论证、C6 的对比都是读论文后的分析，不需要跑。C1 没有做在线越狱测试，C2 没有跑对照实验，C5 的译版是手写的不是模型输出——这三处文中都写了，没有拿模拟数据充结果。

## 关于 C3 的两处存疑

课件点名了 Kimi K2.5 和 GLM5 两份报告。GLM-5 只在 Hugging Face 上见到仓库，技术报告的方法章节没有公开版本；Kimi K2.5 没有找到一手材料。所以 C3 的技术论证只用了 InstructGPT、DeepSeek-V3、R1、Qwen3、V3.2 五份，这两家只在结尾提了一句猜想。
